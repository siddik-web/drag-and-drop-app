# Layout Builder App

This is a minimal MVP version of the Layout Builder app. It allows users to add, edit, and drag-and-drop components to build a layout.

## Setup

1. Clone the repository.
2. Run `npm install` to install the dependencies.
3. Start the app with `npm start`.

## Features

- Add text components.
- Drag and drop components.
- Sidebar to add more components.
